# AppleCheck

AppleCheck — мобильное приложение для ОС Аврора, использующее модели компьютерного зрения для оценки качества яблок по фотографии. Пользователь может сделать снимок камерой или выбрать изображение из галереи, после чего приложение классифицирует результат как «Хорошее яблоко», «Плохое яблоко» или «Не яблоко». Дополнительно поддерживается офлайн-дообучение на устройстве для адаптации модели к новым условиям. Репозиторий содержит рабочий каркас приложения на Qt/QML: QML-интерфейс, C++ бэкэнд с простейшим классификатором на основе эвристик (средняя насыщенность + округлость), заготовку для локального дообучения и сборку CMake под Qt 6/Qt 5.15.

## Возможности
- Захват изображения с камеры устройства или загрузка из галереи.
- Сегментация объектов с помощью моделей YOLO11-segm и YOLACT.
- Формирование решения («Хорошее яблоко», «Плохое яблоко», «Не яблоко») через MLPack или TFLite.
- Опциональное офлайн-дообучение модели прямо на устройстве.
- Удобный интерфейс на QML с подсказками и понятными элементами управления.

## Архитектура
- **Бэкэнд (C++/Qt)**: класс `UiController` предоставляет Q_INVOKABLE-методы для классификации и дообучения, управляет состоянием загрузки и выводом уведомлений. Класс `ImageClassifier` реализует эвристическую оценку изображения (насыщенность + округлость), которую можно заменить на NCNN/MLPack/TFLite.
- **Интерфейс (QML/QtQuick)**: главный экран `qml/Main.qml` с выбором изображения, отображением превью, статусом классификации, прогресс-баром уверенности и тост-уведомлениями. Диалоги позволяют выбрать файл или папку с данными для дообучения.
- **Камера**: компонент Qt Multimedia легко добавляется в `Main.qml` (кнопка «Сделать снимок» может быть привязана к `Camera`/`ImageCapture`), исходный каркас уже готов к расширению.
- **Модели**: текущий прототип использует эвристику, но в `ImageClassifier` можно подключить загрузку NCNN/TFLite весов и предобработку через OpenCV. Для этого предусмотрен единый вход `classify(const QImage&)`.
- **Обучение на устройстве**: метод `trainOnDataset` сейчас эмулирует быстрое выполнение и уведомляет пользователя; сюда можно встроить пайплайн MLPack для дообучения и сохранения весов.

## Поток данных
1. Пользователь выбирает «Сделать фото» или «Из галереи».
2. Кадр нормализуется (масштабирование, выравнивание цвета) и передаётся в модуль сегментации.
3. Результаты сегментации подаются в классификатор качества (MLPack/TFLite), который возвращает итоговую метку.
4. Интерфейс отображает метку, вероятности и подсказки (например, переснять при плохом освещении).
5. При включённом офлайн-дообучении пользователь может добавить примеры; модель обновляется на устройстве и сохраняется в пользовательском хранилище.

## Требования к окружению
- ОС Аврора (физическое устройство или эмулятор).
- Qt 6 (QtQuick, Qt Multimedia) или Qt 5.15 (Aurora), C++17.
- (Опционально) OpenCV, NCNN, MLPack или TFLite — для замены встроенной эвристики на реальные модели.
- Aurora Conan для получения совместимых бинарных пакетов.

## Сборка и запуск (каркас приложения)
1. Установить Aurora SDK и Aurora Conan.
2. (Опционально) Получить сторонние зависимости через Conan.
3. Собрать проект:
   ```bash
   mkdir -p build && cd build
   cmake .. -DCMAKE_BUILD_TYPE=Release
   cmake --build .
   ```
4. Запустить собранный бинарь `AppleCheck` на устройстве или эмуляторе; QML-интерфейс отобразится сразу.
5. Для добавления камерного захвата в `Main.qml` подключите `Camera` и `ImageCapture`, передавайте путь на `uiController.classifyImage()`.

## Проверки качества
- Автоматические тесты (юнит-тесты C++) для модулей препроцессинга и классификации.
- Интеграционные тесты QML для проверки навигации и корректности отображения результата.
- Валидация через инструменты Аврора для проверки разрешений камеры, хранения данных и производительности.

## Работа с данными пользователя
- Результаты инференса и настройки сохраняются в пользовательском хранилище и доступны между сессиями.
- Для дообучения примеры хранятся локально; перед началом пользователь подтверждает сохранение.
